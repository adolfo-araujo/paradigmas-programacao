## O que mudou

- Os códigos-fonte mantêm seus nomes e conteúdo originais.
- Projetos orientados a objetos mantêm seus arquivos relacionados na mesma pasta; a execução deve ocorrer **dentro** da pasta Python ou Java correspondente.
- Os READMEs Java existentes tiveram somente as instruções de caminho atualizadas.
- Configurações pessoais de `.vscode/`, pastas `bin/` e diretórios vazios `lib/` não são necessários no repositório e não foram copiados.
- O antigo `LEIA-ME.md` foi preservado em `docs/LEIA-ME-ORIGINAL.md` como documento histórico, podendo mencionar a estrutura anterior.
- Foram adicionados README principal, `.gitignore`, guia de execução e um verificador de compilação.

## Conteúdo dos PDFs das aulas

Os arquivos de aula foram usados como referência para identificar os assuntos, mas **não foram incluídos no ZIP de publicação**. Caso haja autorização do professor para redistribuí-los, essa decisão pode ser avaliada separadamente.

## Limites da validação

As verificações automatizadas cobrem compilação e sintaxe, não avaliações de corretude funcional, segurança, interfaces ou todas as entradas possíveis. Não foram alteradas as implementações acadêmicas para evitar mudanças de comportamento não solicitadas.
